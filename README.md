# فرص عمادة شؤون الطلاب

صفحة عربية عامة تعرض المنشورات ذات الصلة من حساب [@1_dsa1](https://x.com/1_dsa1)، حساب عمادة شؤون الطلاب بجامعة شقراء.

## ماذا تعرض الصفحة؟

تقرأ الصفحة ملف `data.json` الثابت، وتوفر بحثًا نصيًا وتصنيفًا للمنشورات ضمن الدورات والبرامج التدريبية وورش العمل والمحاضرات والحملات والبطولات والمسابقات والمبادرات.

كل بطاقة تحتوي على نص مختصر وتاريخ ورابط مباشر إلى المنشور الأصلي على X. لا يتم نسخ الصور أو إعادة نشر المحتوى المرئي؛ بل يبقى المصدر الأصلي هو المرجع.

## التحديث التلقائي

يعمل سير العمل الموجود في `.github/workflows/update.yml` كل ست ساعات، وكذلك عند تشغيله يدويًا من تبويب **Actions**. يقوم `scripts/fetch_posts.py` بقراءة الصفحة العامة للحساب، واستخراج المنشورات الحديثة، وتصفية الكلمات المفتاحية، وتصنيف النتائج، ثم تحديث `data.json`. إذا حجب X طلب GitHub Actions، يستخدم السكربت قارئًا عامًا احتياطيًا ويحتفظ بروابط المنشورات التي سبق التعرف عليها.

يعتمد الجامع على HTML العام للحساب، لذلك قد يتوقف مؤقتًا إذا غيّر X بنية الصفحة أو منع الطلبات العامة. عند حدوث ذلك، يحتفظ المستودع بآخر نسخة ناجحة بدل استبدالها ببيانات فارغة، وتظهر الصفحة رسالة واضحة للمستخدم.

## تشغيل محلي

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000`.

لتحديث البيانات محليًا:

```bash
python3 -m pip install beautifulsoup4
python3 scripts/fetch_posts.py
```
