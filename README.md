# يومي الذكي

لوحة تحكم عربية RTL لإدارة المهام اليومية، مبنية كنسخة MVP ثابتة تعمل بالكامل داخل المتصفح.

المستودع: https://github.com/dkdsgf/smart-daily-dashboard

## المزايا

- إضافة وتعديل وحذف المهام.
- حالات قادمة، قيد التنفيذ، ومكتملة.
- تصنيف وأولوية وموعد ومدة ومستوى طاقة.
- بحث وتصفية ونسبة إنجاز.
- اقتراح المهمة التالية تلقائيًا.
- مؤقت تركيز 25 دقيقة.
- حفظ محلي تلقائي عبر `localStorage`.
- ملخص أسبوعي مبسط.

## التشغيل

شغّل أي خادم ملفات ثابت من جذر المشروع، مثل:

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000`.

## الخصوصية

لا يرسل التطبيق المهام إلى خادم؛ تُحفظ على الجهاز في `localStorage`. حذف بيانات الموقع من المتصفح يحذف المهام المحفوظة.
